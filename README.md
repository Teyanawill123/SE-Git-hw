\# SE-Git-hw



\## Overview



This repository was created for my Software Engineering Git and GitHub assignment.



\## Project Purpose



The purpose of this project is to demonstrate basic Git and GitHub functionality, including repositories, commits, branches, pull requests, merge conflicts, and GitHub Issues.



\## Files



\- `hello.py` - A Python program that prints a Hello World message.

\- `apple.py` - A Python program that prints "I eat apple".



\## Git Features Demonstrated



\- Git configuration

\- GitHub repository creation

\- Repository cloning

\- Commits

\- Push and pull operations

\- Branch creation

\- Feature development

\- Pull requests

\- Pull request review

\- Branch merging

\- Merge conflict creation and resolution

\- GitHub Issues



\## Branches



\### main



Contains the main version of the project and the completed programs.



\### feature-1



Used to develop and add the apple program before it was merged into the main branch.



\### conflict-branch



Used to demonstrate the creation and resolution of a merge conflict.



\## Pull Requests



A pull request was created from `feature-1` to `main` to merge the apple program into the main branch.



A classmate's pull request was also reviewed and approved as part of the assignment.



\## Merge Conflict



A merge conflict was intentionally created by changing the same line in `hello.py` differently on the `main` and `conflict-branch` branches.



The conflict was manually resolved by selecting a final version of the Hello World message. The resolved file was then committed and pushed to the main branch.



\## GitHub Issues



Two GitHub Issues were created to track project tasks. One issue was assigned to me and another was assigned to a classmate. Both issues were completed and closed.
